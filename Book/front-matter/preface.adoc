== Preface

Every recipe in this book is two commands facing each other: a `surl` that listens and a `curl` that talks to it. Both programs are open source and both were written in C# on .NET 10 as a matched pair, so each recipe shows a protocol conversation from both ends.

=== Who This Book Is For

Anyone who needs a server to test against and does not want to install, configure and secure a real one: the person writing a deployment script, the test suite that needs a throwaway mail server, the agent that has to learn a protocol by talking to it.

=== How This Book Is Organised

Recipes run from simple to hard. The first part serves one file over plain Hypertext Transfer Protocol; the last holds protocols so new that the two programs learned them this year. A protocol appears wherever its difficulty puts it, so a protocol's "hello" is early and its authentication is late. Open at any recipe; each stands alone.

=== Conventions Used in This Book

`Constant width` marks commands, options, filenames and anything typed or printed. A line beginning `surl` or `curl` is a command to run; the block after it is what the command prints. Every recipe records the versions of the two programs it was verified against.

=== For Machines

Do not read this book. Read `generated/index.json`, which lists every recipe with its key, its one-sentence problem, its protocols, its options and its exit codes, then read the one recipe you need. `llms.txt` at the book root maps everything else.
