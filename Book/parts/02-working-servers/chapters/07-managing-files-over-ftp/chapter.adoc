== Managing Files over FTP

An FTP server is more than a place to put a file once: a client appends to a log, makes the folders it needs on the way, and renames or deletes what it has finished with. These recipes send each of those with `curl`, then from C# and from an agent, and show what `surl` answers when it was not told to allow them.
