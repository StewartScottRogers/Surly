=== Creating Folders While Uploading

==== Problem

You upload a report into a dated folder path such as `2026/11/12/`, and the folders may not exist yet. You want the upload to make them rather than fail, without a separate command for each level.

==== Solution

Serve a directory that accepts anonymous logins and uploads, and add `--ftp-create-dirs` to the upload:

==== Discussion

File Transfer Protocol (FTP, <<rfc959>>) uploads into the current folder of the connection, so before `STOR` `curl` changes into each folder of the path in turn with `CWD`. When a folder is not there the server answers `550 No such directory`, and by default `curl` gives up: it exits `9`, remote access denied, and nothing is made. `--ftp-create-dirs` makes `curl` send `MKD`, make a directory, for the folder that failed, change into it, and go on to the next. The path above has three folders and the first, `2026`, already exists, so `curl` makes `11` and then `12` and stores the file in `12`.

`-v` shows it. Folders that exist are entered and not made: a new path ending in `13` sends `MKD 13` only, and the same command again sends no `MKD` at all and replaces the file. The option is therefore safe to leave on for every upload of a job that may run twice. `--directory site` serves the files under `site`, where the cases look for what was made. `-T report.txt` names the local file, `-s` keeps the progress meter away, and `-l` lists a folder{apos}s names one a line so the cases can see what was made. A listing needs `--list-directories` on the server, since `surl` does not list folders unless asked.

The server decides whether `MKD` is allowed. `--allow-uploads` permits it as it permits `STOR`; it loosens the server, though `surl` prints no warning for it. Without it the answer is `550 Not permitted`, the folder is not made, `curl` still exits `9` and the listing shows what was there before. `--allow-anonymous` lets `curl`{apos}s anonymous login in and checks nothing, so it is for a test on your own machine only (<<surl-readme>>); a server started without it refuses the login and `curl` exits `67`, login denied (<<curl-readme>>).
