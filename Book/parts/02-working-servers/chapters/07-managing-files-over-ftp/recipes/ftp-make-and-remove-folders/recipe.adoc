=== Making and Removing FTP Folders

==== Problem

You want to make a folder on a File Transfer Protocol (FTP) server, remove an empty one, and see what the server says when a folder still holds a file.

==== Discussion

FTP (<<rfc959>>) has a command for each: `MKD` makes a folder and `RMD` removes one. `curl` has no option for either, but `-Q`, a quote, sends any command to the server, here before the transfer. A quote needs a transfer to ride on, so the examples ask for the listing of a folder; `-l` prints its names one a line, and `--list-directories` on the server lets it list folders at all, which `surl` does not do unless asked. `--directory site` serves the files under `site`, which is where the cases look for what was made. The listing after `MKD reports` holds `reports` beside `hello.txt`, and the folder is a real one in the served directory. `MKD` is answered `257 "/archive" created`, naming the path it made; `-v` shows the command and the reply, and the cases keep the two lines.

`MKD` makes the last folder of its path and no more. With a path whose parent is there, `reports/2026` is made inside `reports`. With a parent that is not there the answer is `550 No such directory` and nothing is made: unlike `--ftp-create-dirs` on an upload (<<ftp-create-folders-while-uploading>>), a quote makes no parent. For a folder that is already there the answer is `550 Already exists`, and `curl` exits `21`, quote command failed.

`RMD` removes an empty folder, answered `250 Directory removed`, and the root listing no longer holds it. A folder that still holds a file is refused: `550 Directory not empty`, `curl` exits `21`, and the folder and its file are as they were. The way out is to delete what is in it first. `-Q` may be given again and the commands run in order, so `-Q "RMD reports/2026" -Q "DELE reports/note.txt" -Q "RMD reports"` removes the inner folder, deletes the file and then removes the folder, exit `0`. A name that is not there, or is a file and not a folder, is `550 No such directory`.

`--allow-uploads` permits `MKD`, `RMD` and `DELE` as it permits `STOR`; it loosens the server, though `surl` prints no warning for it. Without it `MKD` and `RMD` are answered `550 Not permitted`, even for an empty folder. `--allow-anonymous` lets `curl`{apos}s anonymous login in and checks nothing, so it is for a test on your own machine only; a server started without it refuses the login before either command is sent, and `curl` exits `67`, login denied (<<curl-readme>>). `-T note.txt` uploads a file, `-o` with the null device throws the listing away, and `-s` keeps the progress meter out.
