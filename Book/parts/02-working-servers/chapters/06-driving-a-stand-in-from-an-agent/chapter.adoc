== Driving a Stand-In from an Agent

The same seeding, waiting and resetting, as an artificial intelligence (AI) agent does them through `surl-mcp` and `curl-mcp` over the Model Context Protocol (MCP). Each recipe is a C# program on the official MCP software development kit (SDK) that starts both hosts, calls their tools and prints what it gets back.
