== Testing an App Against a Stand-in

Each recipe runs an app against `surl` as a stand-in for a real server, File Transfer Protocol (FTP) or mail, and checks what the app did from the server's side after it has finished: the files it left, the flags it set. The check is part of the test: it fails the build when the server holds something it should not, or lacks something it should.
