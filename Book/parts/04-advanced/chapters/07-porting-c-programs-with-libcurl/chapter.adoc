== Porting C Programs with Libcurl

Each recipe takes a C program written against one of libcurl's application programming interfaces (the URL parser, MIME forms, the header reader, the transfer timers) and ports it call for call to C# with `Libcurl`, keeping libcurl's names, numbers and error codes. Each port is run against `surl`, which shows what the program sent or makes the server behave in a way the program has to report.
