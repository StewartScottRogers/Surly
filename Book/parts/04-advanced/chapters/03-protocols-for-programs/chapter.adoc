== Protocols for Programs

Some of what `surl` serves is for programs, not for the `curl` tool: WebSocket messages both ways and Real Time Streaming Protocol (RTSP) sessions. These recipes drive them with `Libcurl`, the libcurl interface for C#, one call for one call.
