==== Discussion

A HAR file is JavaScript Object Notation (JSON): a `log` with a `version`, a `creator` and one entry per request, each holding the request, the response and how long each part took. `curl` already reports every piece of that; the script only puts the pieces where HAR wants them, one `curl` per URL:

* `-v` writes the request as `curl` sent it to standard error, each header line marked `> `; the script keeps those lines, so the request headers are the real ones, `Host`, `User-Agent` and `Accept` here, in the order sent.
* `-D head.tmp` saves the response's status line and headers as `surl` sent them, which give the response's `status`, `statusText` and `headers`.
* `-o body.tmp` saves the body, which goes into `content.text` base64-encoded, so any bytes survive the trip into JSON; `-s` keeps the progress meter out of the way.
* `-w` prints the method, HTTP version, status, size, `Content-Type` and `curl`{apos}s own clocks. HAR wants milliseconds; `curl` gives seconds, so `send` is the time until the request could go (`time_pretransfer`), `wait` the time from then to the first byte of the answer, `receive` the rest, and `time` the whole.

The `pairs` function turns `Name: value` lines into HAR{apos}s `{"name": ..., "value": ...}` objects and escapes backslashes and quotes on the way, which is all JSON needs from a header. The case checks the result with Python{apos}s `json` module: version 1.2, two entries. That is the check the file is well formed; this recipe does not load it into a browser.

`--directory site` makes `surl` serve the folder the requests go to, `hello.txt` in it and `missing.txt` not. A `404` is saved like any other answer, status `404`, `Not Found` and `surl`{apos}s short body, the same `404 Not Found` as text, because to `curl` it is an answer and `curl` exits 0. A request that gets no answer at all is different: there is nothing to save, so the script stops with `curl`{apos}s exit code, 7 for a port where nothing listens, and removes the part file it was writing, leaving no half-written HAR behind.

What the script leaves out: request bodies (it sends only GET), cookies, and the header sizes, which HAR allows as `-1` for unknown. The timings are the client's, from `curl`; `surl`{apos}s view of the same exchanges is its trace (see <<http-check-headers-reach-the-server>>).
