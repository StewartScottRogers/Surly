=== Verifying a Download's Checksum

==== Problem

Your installer must refuse a downloaded file whose SHA-256 digest differs from the published one, and you want a test that keeps the download when the digest matches and refuses it when the served file has changed.

==== Discussion

Over the Hypertext Transfer Protocol (HTTP), `surl` sends the bytes it has and `curl` writes the bytes it got; neither knows what the file should contain, so a file changed on the server downloads as cleanly as the original (<<rfc9110>>). The check belongs to the installer, against a digest published somewhere the attacker cannot also change, and the script is that check in a dozen lines.

`-f` makes `curl` treat a `404` or any other error status as a failure, exit 22, instead of saving an empty file under the installer's name; `-s` hides the progress meter and `-S` keeps the error line. `-o "$file.part"` writes the download beside its final name, not over it. The script hashes the part file with `sha256sum`, or `shasum -a 256` where there is no `sha256sum`, takes the digest from the front of the line, and compares it with the published one as text, so the digest must be given in lower case. On a match it renames the part file to its name and says so; on a mismatch it removes the part file, names both digests on standard error, and exits 1.

Three refusals are shown. A digest that is not the file's is refused, which is what a wrong or truncated published value looks like. A served file that has changed, here by words added to it, gets past `curl` and is refused by its digest. A missing file is refused by `curl -f` before any digest is taken, and the script passes `curl`{apos}s exit code, 22, on. Because the script writes to `tool-1.0.bin.part` and renames only on a match, the refused download of the changed file leaves no part file behind and does not touch the good `tool-1.0.bin` already kept.

`--directory site` serves the folder from disk, so changing `site/tool-1.0.bin` changes what the next request gets, with no restart; that is how the case stands in for a mirror that started serving something else.
