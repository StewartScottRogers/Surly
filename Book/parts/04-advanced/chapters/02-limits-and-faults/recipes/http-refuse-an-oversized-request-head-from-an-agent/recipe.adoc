=== Refusing Oversized Request Heads from an Agent

==== Problem

Your client sometimes sends huge cookies, and the real server refuses them. You want an artificial intelligence (AI) agent to start a Hypertext Transfer Protocol (HTTP) test server that answers `431` when a request head is over a size you choose, try it with a big cookie and a small one, and see what the server sent back, all with Model Context Protocol (MCP) tool calls.

==== Solution

Write the agent's side as a C# program on the MCP software development kit (SDK): it calls `surl-mcp`{apos}s `start_server` with `--max-request-head 1k` in `arguments`, then `curl-mcp`{apos}s `transfer` with a 1,200-byte `Cookie` header:

==== Discussion

The program starts both hosts by name with `StdioClientTransport`, each confined to the folder it runs in by `SURL_MCP_ROOT` or `CURL_MCP_ROOT`; `mcp.json` beside the recipe is the same configuration for an agent's own client. The argument after `--` picks the scenario. `start_server` takes `surl`{apos}s options in `arguments`, as the words `surl` takes on its command line, so `["--max-request-head", "1k"]` sets the limit to 1,024 bytes. The answer is structured content, a JavaScript Object Notation (JSON) element, holding `server_id`, which the other `surl-mcp` tools take, and `bound_urls`, the URL with the port the system chose for port 0. `files` puts `hello.txt` in the server's store in memory.

A request head is the request line and every header line up to the blank line that ends them. `transfer` takes extra request headers as a list of `name` and `value` pairs, and the program sends one `Cookie` of 1,200 bytes, which puts the head over 1 KiB. `surl` answers `431 Request Header Fields Too Large`, though `hello.txt` is there. `curl-mcp` answers in text, as JSON: `statusCode` is `431`, `failure` is null, and the call is not a tool error, because a `431` is an answer like any other; the agent has to read the status. The body is empty, `totalBytes` `0`, and the `Connection: close` header says the server is not keeping the connection for another request.

The `small` scenario sends a 600-byte cookie, which fits, and gets the file. The `default` scenario leaves `arguments` empty, and the 1,200-byte cookie is served under `surl`{apos}s default limit.

`get_exchanges` shows what crossed each connection, byte for byte, as chunks with a `direction`; the program joins the `sent` chunks of the last exchange and prints their first line, `HTTP/1.1 431 Request Header Fields Too Large`. That is the server's own record of the refusal, which an agent can read without trusting the client's report.
