=== Serving Files from Memory

==== Problem

Your C# test needs a few text and binary files served over Hypertext Transfer Protocol (HTTP), some of them in nested folders, and you want to hand them to the server as bytes in `Files` rather than write a folder to disk first.

==== Solution

Put each file in `SurlServerOptions.Files` under the path it is to be served at, start the server, and fetch each one, checking that the bytes that come back are the bytes given:

==== Discussion

`SurlServerOptions.Files` is a dictionary from path to bytes. The key is the path relative to the served root, its segments separated by `/`: `docs/guide/intro.txt` is served at `/docs/guide/intro.txt`, and the folders `docs` and `docs/guide` exist because a key is inside them, with nothing to create first. The value is the file's bytes, whatever they are; a Portable Network Graphics (PNG) image comes back byte for byte. `ListenUrls` and port 0 work as in any in-process recipe, and `SurlServer.StartAsync` returns the running `SurlServer` with `BoundUrl` naming the port it got. `CurlClient.Create()` makes the client, each request is a `CurlRequest`, and `CurlClient.SendAsync` returns a `CurlResponse` whose `Headers` carry the `Content-Type` and whose `Body` the program copies into memory to compare.

`Files` holds bytes and nothing else, so the server chooses the `Content-Type` from the key's extension: `text/plain` for `.txt`, `image/png` for `.png`. Name a file for the type a client should see.

A folder is not a file. `/docs/guide/` is `404 Not Found`, as is any path not in `Files`. A key whose last segment begins with a dot, such as `docs/.draft`, is accepted and never served, `404`, as a dot file in a served folder is not.

`StartAsync` checks every key before anything binds and throws `ArgumentException` for one it will not take: a key that starts with `/`, one with a `..` segment, one separated with `\`, and one that names a folder another key is inside, such as `docs/guide` beside `docs/guide/intro.txt`. The separator is `/` on every platform, no key may reach outside the served root, and no path may be both a file and a folder. This program exits 2 when it catches one. The `--key` argument adds one key of your own to try.
