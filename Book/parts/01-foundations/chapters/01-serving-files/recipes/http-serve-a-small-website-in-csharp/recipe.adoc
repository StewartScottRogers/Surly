=== Serving a Small Website in C#

==== Problem

Your C# user-interface test needs a small website served from memory over Hypertext Transfer Protocol (HTTP), and you want to seed its pages, styles, scripts and images with `Surl.Api` and check with `Curl.Api` that each arrives with the right `Content-Type`.

==== Solution

Put each file{apos}s bytes in `SurlServerOptions.Files`, start the server on a free port, and fetch every path with a `CurlClient`, comparing status, type and bytes with what the test expects:

==== Discussion

`SurlServerOptions` is `surl`{apos}s command line as properties. `Files` is the in-memory store, a relative path with `/` between folders mapped to the file{apos}s bytes, so `css/site.css` is served at `/css/site.css` and the page{apos}s relative links resolve. Bytes are bytes: the eight-byte Portable Network Graphics (PNG) signature in `img/logo.png` is not valid UTF-8 and comes back unchanged. `ListenUrls` holds `http://127.0.0.1:0`, a free port, and `SurlServer.StartAsync` returns once it is bound; `BoundUrl` is the address to put in front of each path.

`surl` sets `Content-Type` from the extension (<<surl-readme>>): `text/html`, `text/css`, `text/javascript`, `image/png`, `image/svg+xml` and `application/json` here, with no `charset` parameter, and `application/octet-stream` for an extension it does not know, such as `.xyz`. It does not look inside the bytes.

`CurlClient.SendAsync` sends each `CurlRequest` and returns a `CurlResponse`. `Headers` is every header as received, in order, with its casing (<<curl-readme>>); header names are case-insensitive (<<rfc9110>>), so the program compares them that way. `Body` is a stream; the program reads it to the end and compares the bytes with what it seeded. A path whose status, type or bytes differ prints `WRONG`, and the program exits `1`, which is how a test fails.

There is no index page: the root path is answered `404 Not Found` with no `Content-Type`, so a test that drives a browser opens `/index.html` by name. The server is stopped when `await using` disposes it.
