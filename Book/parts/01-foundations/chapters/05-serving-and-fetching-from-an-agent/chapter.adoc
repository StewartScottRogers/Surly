== Serving and Fetching from an Agent

The same listener and request again, as an artificial intelligence (AI) agent makes them through `surl-mcp` and `curl-mcp`, the two programs' Model Context Protocol (MCP) servers. Each recipe is one C# program on the official MCP software development kit (SDK) that starts both hosts, calls their tools as an agent would, and runs with `dotnet run`.
