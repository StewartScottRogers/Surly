=== Stopping Every Server

==== Problem

Your artificial intelligence (AI) agent has started several test servers and is done with them. You want it to clean up after itself: list what is running, stop each server, and confirm that the ports it held are free again.

==== Solution

Write the agent{apos}s side as a C# program on the official Model Context Protocol (MCP) software development kit (SDK): it calls `surl-mcp`{apos}s `list_servers`, then `stop_server` for each server listed, then `list_servers` again, and finally `start_server` on every URL a stopped server held, to show each port can be bound:

==== Discussion

`StdioClientTransport` starts `surl-mcp` from `PATH`, confined to the program{apos}s folder by `SURL_MCP_ROOT` (<<mcp-spec>>). The program first does what an agent{apos}s earlier work would: `start_server` twice on port 0 of the loopback address, the second time with two listen URLs, so that server has two Hypertext Transfer Protocol (HTTP) listeners, each on its own free port.

`list_servers` takes no arguments and answers, in structured content, a `servers` list with each server{apos}s `server_id` and `bound_urls`: every URL it listens on, with its real port. That is the agent{apos}s inventory; it need not have remembered what it started or on which ports. The program keeps every bound URL from that answer, three here, before it stops anything. `stop_server` takes one `server_id` and answers `exit_code` 0, `exit_code_name` `Ok`, the code a `surl` process exits with when stopped (<<surl-readme>>). One call stops a server and every listener it has. `list_servers` then answers an empty list.

An empty list says the host has no servers; it does not by itself say the ports are free. The program checks that directly: it calls `start_server` with each URL a stopped server held, port and all, stops the new server again, and counts the binds that succeeded. Three of three: every port is free, the two-listener server{apos}s both included. While a server runs, the same call fails: a tool error with `exit_code` 45, `BindFailed`, `surl`{apos}s exit code for an address already in use. So the check fails loudly for a port still held rather than passing because a list was empty.

A host lists and stops only the servers it started itself, and its servers end when it ends (<<surl-clean-up-leftover-servers>> shows both); an agent that keeps one `surl-mcp` for a long session cleans up as here, and one whose session ends gets the clean-up for free.
