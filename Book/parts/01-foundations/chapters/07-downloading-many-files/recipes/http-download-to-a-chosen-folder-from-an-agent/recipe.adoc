=== Choosing Where Downloads Land from an Agent

==== Problem

You want an artificial intelligence (AI) agent to save files it fetches over Hypertext Transfer Protocol (HTTP) under names and in folders it chooses inside its `curl-mcp` root, and to know what happens when it names a path outside that root.

==== Solution

Write the agent{apos}s side as a C# program on the official Model Context Protocol (MCP) software development kit (SDK): it starts `surl-mcp` and `curl-mcp`, calls `start_server` with two files, then calls `curl` with `--create-dirs`, `--output-dir`, `-o` and `-O`:

==== Discussion

`StdioClientTransport` starts each host by name from `PATH`, and `SURL_MCP_ROOT` and `CURL_MCP_ROOT` confine both to the folder the program runs in. `start_server` starts a server that answers as `surl` would, on a free port, with `files` held in memory: `docs/guide.txt` is served at `/docs/guide.txt`. Its structured content gives the real address in `bound_urls` (<<surl-readme>>).

The `curl` tool runs `curl` with `args`, one item per argument and no shell to quote for. The options mean what they mean on the console. `-o handbook.txt` names one file; `-O` takes the other{apos}s name from the last part of its URL, `summary.txt`. `--output-dir downloads` puts both in `downloads`, and `--create-dirs` makes it. `-w "%{filename_effective}\n"` prints each file{apos}s path, and `-s` keeps the progress meter out, so standard output holds only those two lines. `curl-mcp` answers in text, as JavaScript Object Notation (JSON): `exitCode` is 0, and the agent reads the files back from the root it shares with the host.

Every argument that names a local path is checked against `CURL_MCP_ROOT` before `curl` runs (<<curl-readme>>). An `--output-dir ..` or an `-o ../guide.txt` resolves outside it and is refused: `failure` is `PathRefused`, its text names the option, the path given and where it resolves, `exitCode` and `standardOutput` are null because `curl` never ran, and the call is a tool error. The root is set by whoever starts `curl-mcp`; an agent cannot widen it with an argument.
