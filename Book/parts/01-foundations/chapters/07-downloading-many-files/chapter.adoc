== Downloading Many Files

These recipes fetch more than one file and save each where it belongs: under a chosen name and folder, in a numbered series, several at once or over one connection. Each is told three ways, with `curl` on the console, with `Curl.Api` from C#, and from an agent through `curl-mcp`.
