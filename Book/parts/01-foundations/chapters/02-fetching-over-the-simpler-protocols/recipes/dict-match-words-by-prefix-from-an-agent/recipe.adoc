=== Finding Words That Match from an Agent

==== Problem

You want an agent to search a glossary served over the Dictionary Server Protocol (DICT) for the words that start with a prefix, and to fetch the definition of the one it picks.

==== Solution

The agent starts the glossary with `surl-mcp`, asks `curl-mcp` for the matches, picks the first word from the list, and asks for its definition:

==== Discussion

`start_server` takes `listen_urls`, here one `dict://` URL on port `0`, which takes a free port, and `files`, content held in memory: each file is a headword, its name the word and its text the definition, in one database named `surl`. The answer{apos}s `bound_urls` has the port taken. The `curl` tool of `curl-mcp` takes curl{apos}s own arguments in `args`, and runs them in-process. Its answer is JSON: `exitCode` and `standardOutput`, whose `content` is the server{apos}s whole reply, status lines included. DICT ends its lines in CR LF and the program prints them as plain new lines.

The question is the path of the URL: `m:`, the word to match, then the database and the strategy, separated by colons, `*` meaning every database. With `prefix` the server lists every headword that starts with the word: `ap` gives `apple` and `apricot` under `152 2 matches found`, one line each with the database, and not `banana`. Leaving the strategy out gives `prefix`. The agent reads the first word off the list and asks `d:apple`, which is answered `150` and `151` naming the word and its database, the definition, and a dot line.

Nothing here is an error to the tool. `exact` matches whole words only, so `m:ap:*:exact` is answered `552 no match`; a strategy the server does not offer, `suffix` for instance, is answered `551 invalid strategy`; and `m:AP` finds nothing, since words are matched as written. In each, `exitCode` is `0` and the tool does not report an error, so an agent has to read the status line, and here it has nothing to pick. `show:strat` is how it finds out what it may ask: the server offers `exact` and `prefix`.
