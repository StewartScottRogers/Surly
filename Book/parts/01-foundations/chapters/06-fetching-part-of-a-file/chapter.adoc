== Fetching Part of a File

These recipes ask the server for a slice of a file instead of all of it, and read what it answers: the bytes asked for, a refusal when they are not there, or the whole file when the request makes no sense. Each is told three ways, with `curl` on the console, with `Curl.Api` from C#, and from an agent through `curl-mcp`.
