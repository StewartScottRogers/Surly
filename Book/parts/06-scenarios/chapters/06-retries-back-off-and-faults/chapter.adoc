== Retries, Back-off and Faults

Each recipe here makes `surl` fail on purpose, with an error reply, a refused login, a dropped connection or a server that stalls, and shows the client retrying, backing off or giving up in bounded time. Both sides keep count, so a test can assert on what the client did and on what the server saw.
