== Logins and Tokens End to End

A client that logs in is tested end to end only when the whole flow runs: the login, what it hands back, the calls made with it, and the refusals when any step is wrong. These recipes run such flows against `surl` over Hypertext Transfer Protocol Secure (HTTPS) and check what the server recorded.
