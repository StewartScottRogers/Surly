== Testing an App That Sends Mail

These recipes put one `surl` behind an app that sends mail, serving your own domain over SMTP, IMAP and POP3, so a test can read back what the app sent, catch every generated address in one mailbox, fail on a recipient outside the domain and clean up afterwards. Most are told three ways, on the console, from a C# test and from an agent, and each checks what the server stored as well as what the client saw.
