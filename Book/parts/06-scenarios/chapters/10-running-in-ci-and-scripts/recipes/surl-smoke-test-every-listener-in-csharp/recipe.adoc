=== Smoke-Testing Every Listener in C#

==== Problem

In a C# test: after standing up a test environment you want one quick check that every listener answers before the suite runs, failing fast on the one that does not.

==== Solution

Send each of the server{apos}s `BoundUrls` one request in its own protocol through a `CurlClient` with a 3-second `Timeout`, and stop at the first that gets no answer:

==== Discussion

The environment is one `SurlServer` whose `SurlServerOptions` hold four `ListenUrls` on port 0: Hypertext Transfer Protocol (HTTP, <<rfc9110>>), File Transfer Protocol (FTP, <<rfc959>>), Simple Mail Transfer Protocol (SMTP, <<rfc5321>>) and Internet Message Access Protocol (IMAP, <<rfc9051>>). `MailDomains` and `Mailboxes` are `--mail-domain` and `--mailbox`, the mail store SMTP and IMAP share. `RecordExchanges` keeps a `SurlExchangeRecord` per exchange in `Exchanges`, each with its `Scheme`.

A port that accepts a connection is not a listener that answers, so `Smoke` asks each one something. It sends a `GET` of the root over HTTP and, over the others, a `CurlRequest` whose method is `NOOP`, the protocol{apos}s command that changes nothing, as `curl -X NOOP` would. `CurlClientOptions.Timeout` is `curl -m`: 3 seconds for the whole request. A `CurlResponse` is an answer: HTTP{apos}s `404` for a directory, SMTP{apos}s `250` reply to its `NOOP` as the `StatusCode`, and 0 for the IMAP `NOOP`, which has no numeric reply. A refusal is an answer too: FTP logs in before any command, and `Curl.Api`{apos}s anonymous login is refused, so `SendAsync` throws `CurlException` with `Code` `LoginDenied`, 67, which the check counts as a pass. The check treats two `CurlCode` values as no answer, picked out by the `catch` filter: `CouldntConnect`, 7, and `OperationTimedOut`, 28. Each check uses its own client, disposed as soon as the check is done.

A listener that accepts and then says nothing, here an SMTP `SurlServer` whose `SurlFault.Delay` holds every connection for a minute, fails after the 3 seconds with `OperationTimedOut`; `Smoke` prints its URL and returns 28, and the IMAP listener after it is never asked. A URL whose server has stopped fails at once with `CouldntConnect`, 7. A test framework would fail the fixture on a nonzero result before the suite starts.

After a passing check the server{apos}s `Exchanges` hold one exchange for each of the four schemes: the check cost each listener one connection.
