== Running in CI and Scripts

These recipes run `surl` and `curl` unattended in a continuous integration (CI) job or a script: many checks from one file, a report per run, URLs built and checked before use, tests skipped when the client lacks what they need. When a run fails, they keep what the server recorded, without its secrets.
