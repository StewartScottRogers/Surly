== Standing Up a Test Environment

A test environment is the set of servers a test run starts before its first test and stops after its last. These recipes start one from a script, a .NET test or an agent: from a file kept in the repository, on ports nobody has to choose, handed to the app under test, and cleaned up when the run is over.
