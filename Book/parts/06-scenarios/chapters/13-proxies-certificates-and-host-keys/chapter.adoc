== Proxies, Certificates and Host Keys

A client that goes through a proxy, trusts a certificate or pins a host key makes a promise about what it connects to. These scenarios hold a client to that promise: each runs it against a server, checks what the server recorded, and shows what the test sees when the promise is broken.
