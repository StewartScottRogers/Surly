== Object Stores and Registries

Each recipe here tests code that writes to a cloud object store or a container registry, with a stand-in on your own machine in place of the account. The checks are the same in every one: what the store holds after the write, whether the bytes are the ones sent, and how the stand-in refuses what it should.
