# Rights and attribution checklist

The bare minimum that protects Stewart Rogers's authorship of this book, from ADR-0003. Tick a box when it is done. The author's boxes are kept to the fewest possible; everything else is done for him.

## Done for the author (no action needed)

- [ ] Editorial log in place: every recipe records the author's accept / reject / send-back and notes
- [ ] Copyright notice with the author's name in every source file header and on every rendered page
- [x] Licence split recorded: prose CC BY-ND 4.0, example code Apache 2.0 (ADR-0003, approved 2026-11-05)
- [ ] Licence files written: `Book/LICENSE.txt` (prose), `Book/LICENSE-CODE.txt` (example code)
- [x] Canonical home: landing page on GitHub Pages under the author's name, built from the repository (ADR-0007)
- [ ] Dated, numbered public editions rendered from the repository
- [ ] Free trademark search run on "Surly" and "Oh Really Media", results reported
- [ ] One-page brief prepared for the attorney hour
- [ ] International Standard Book Number form details prepared
- [ ] Copyright registration fields and AI-disclosure wording prepared

## The author does these, once each

- [ ] Paste in the hand-written foreword (`Book/front-matter/foreword.adoc`)
- [ ] Turn on commit signing: run the two commands given in `Book/build/README.md` once
- [x] Approve the licence split (done 2026-11-05)
